    NexFiremap needs a free FIRMS map key before it can download any detections.

    1. Request one at firms.modaps.eosdis.nasa.gov/api/map_key
    2. Copy .env.example to .env
    3. Set FIRMS_MAP_KEY=your-key and restart the server

      Position feeds (device tokens)

      Each field device posts positions with its own token, checked per request — no browser session involved. A token is shown exactly once, at creation or rotation; only its hash is stored, so a lost token can only be rotated, never recovered. Rotating locks the old token out immediately.

      Display

      Satellite coverage

      How recently a tracked satellite's orbit passed over each area today - brighter means a more recent look. A geometric approximation from orbit data (not cloud/quality checked): it answers "was this area even watched", not "was it seen clearly".

      Industrial/static sources

      Recurring non-wildfire heat (flares, kilns, refineries, power plants) identified from OpenStreetMap + this server's own cached detection history - never deletes anything, only distinguishes. Switching this on scans the current view automatically (small/medium views only); use "rescan now" to force a refresh or check a large area on purpose.

      EUMETSAT confirmation

      Independent geostationary fire detection from EUMETSAT's MTG/FCI "Active Fire Monitoring" instrument (~10 minute revisit, Europe / Africa / Atlantic / Middle East only) - a second, differently-sourced satellite confirming (or not) what FIRMS sees, not a magnitude cross-check (this product reports confidence, not radiative power). Known false-positive mode: low-confidence hits over water/sun-glint.
